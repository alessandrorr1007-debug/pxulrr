UPAO S · Aplicación Android

        

        
      

      

        
        

          Aplicación móvil nativa construida para centralizar la experiencia académica de estudiantes universitarios: acceso rápido a cursos, calificaciones, asistencia, horarios y tareas sincronizadas con Canvas LMS.
        

        
Arquitectura y Tecnologías

        
Kotlin · Jetpack Compose · Material 3 · Retrofit · OkHttp · DataStore · WorkManager · Canvas LMS · GitHub Releases

        
Aspectos destacados

        
    
          
  • Interfaz declarativa moderna construida con Jetpack Compose y Material 3.
    • 
          
  • Sincronización periódica y alertas académicas mediante WorkManager.
    • 
          
  • Distribución directa de versiones mediante página web oficial y GitHub Releases.

          Web App · PWA Offline
          
Armador de Horarios UPAO

        

        
      

      

        
        

          Herramienta web progresiva que genera automáticamente combinaciones válidas de horarios sin cruces horarios, permitiendo comparar alternativas y exportar el resultado final listo para matrícula.
        

        
Arquitectura y Tecnologías

        
JavaScript · HTML5 / CSS3 · Backtracking · Web Workers · Service Workers (PWA) · localStorage · Exportación PNG / PDF / .ics

        
Aspectos destacados

        
    
          
  • Algoritmo de backtracking ejecutado en Web Workers para mantener fluidez de interfaz.
    • 
          
  • Funcionamiento offline instalable mediante Service Workers y persistencia en localStorage.
    • 
          
  • Exportación directa a imagen PNG, documento PDF y archivo de calendario .ics.
