App móvil · Android Nativo

UPAO S · Aplicación Android

Centralización académica para estudiantes de la UPAO

Descripción del proyecto

Aplicación Android nativa creada para facilitar la consulta de calificaciones, horario semanal y control de asistencias de estudiantes de la UPAO en una sola interfaz rápida y moderna.

Implementación clave

  • Interfaz nativa: diseñada con Kotlin, Jetpack Compose y Material 3.
  • Integración y utilidades: conexión con Canvas LMS, calculadora de notas, persistencia local con DataStore y notificaciones con WorkManager.
  • Distribución: publicación de versiones APK gestionadas mediante GitHub Releases.

Stack: Kotlin · Jetpack Compose · Material 3 · Retrofit · OkHttp · DataStore · WorkManager · Canvas LMS · GitHub Releases

Herramienta web · PWA

Armador de Horarios UPAO

Planificador académico inteligente sin cruces de horario

Descripción del proyecto

Herramienta web progresiva que procesa cursos del portal UPAO y calcula automáticamente combinaciones válidas respetando las ligas obligatorias entre teoría, práctica y laboratorio.

Implementación clave

  • Motor combinatorio: algoritmo de backtracking para descartar cruces y respetar restricciones de ligas.
  • Rendimiento fluido: cálculo aislado en Web Workers con persistencia en localStorage y soporte PWA offline.
  • Exportación directa: descarga de horarios listos en PNG, PDF e iCalendar (.ics).

Stack: JavaScript · HTML5 / CSS3 · Backtracking · Web Workers · Service Workers (PWA) · localStorage · PNG / PDF / .ics

PremiumPe · Pases y Membresías

Catálogo de suscripciones digitales en Perú con gestión en tiempo real

Descripción del proyecto

Plataforma web orientada al mercado peruano para exhibir pases digitales y membresías con precios en soles, disponibilidad actualizada al instante y administración centralizada.

Implementación clave

  • Frontend moderno: interfaz rápida construida con React, Vite y Tailwind CSS.
  • Datos en tiempo real: integración con Supabase para sincronizar productos, precios y stock al instante.
  • Panel administrativo: gestión directa de catálogo y publicación continua en Netlify.

Stack: React · Vite · Tailwind CSS · Supabase · PostgreSQL · Netlify
